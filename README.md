## 📖 Sobre

**Phone Store** é a landing page do meu primeiro projeto no desenvolvimento front-end! 🚀  
Neste projeto, utilizei **HTML** para estruturar a página e **CSS** para criar um design estiloso e funcional. A landing page foi projetada para representar uma loja de smartphones, destacando-se pela sua **apresentação visual atrativa** e **design responsivo**.  

### 🚀 Aprendizados
- Criação de layouts **responsivos** e visualmente atrativos.
- Estruturação de páginas web com **HTML**.
- Estilização e aperfeiçoamento da interface com **CSS**.
